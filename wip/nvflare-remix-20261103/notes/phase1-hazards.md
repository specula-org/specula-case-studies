Cut decisions that are not obvious:

- The resource consumer's CP-global `CUDA_VISIBLE_DEVICES` write sits in CP.Exec, not CP.Res. That makes B03 (allocate/free) benign and keeps MC-8's whole race (consume on initial START only, env snapshot at every spawn) inside one group; CP.Res can stay coarse in every scenario.
- SJ.Ctl / SJ.Assign / SJ.Model are separate although B07/B08 are bug-prone. The hazards there cross through a small synchronous port (callback frame ok/raised, completion status before task_done, accept outcome incl. partialFailed, save failure after replace). If the coarse variants keep those outcomes (column 7), MC-4/TV-1 need only SJ.Ctl fine. Merging would put WFComm, every controller policy and the aggregator into one group.
- PaySrc and PayRcv are separate because B10 is a message protocol: MC-9 and the seed's S1 race are entirely source-side given adversarial delivery, so a coarse receiver that may emit any legal pull/confirm/cancel sequence suffices. The receiver group still matters on its own: it owns the SJ fatal-exit decode policy (H29/H30) and the Attach confirm-before-acceptance order (H01).
- SP.Job stays one group: its two bug-prone races (#5300 fixed, #5301 accepted) are between the scheduler loop and the completion thread (B23).
- CJ.Trainer (CJ side, including the in-process trainer thread) is split from TP.Trainer (external process or Attach peer) along the RESULT_READY/STATUS/heartbeat protocol. In-process mode needs only CJ.Trainer.

### 3.1 Property definitions (over port state)

Port names: `launch[c][j][g]` (CP.Exec), `alloc[c][j]`, `freeCalls` (CP.Res), `inSlot`, `resultSlot`, `canonical`, `stopCause` (CJ.Trainer), `tpSend` (TP.Trainer), `clientTasks`, `cbRuns`, `completion` (SJ.Assign), `contrib`, `published[g]` (SJ.Model/SJ.Ctl), `txs`, `refTable`, `failedByCancel` (PaySrc), `sjExitCause` (SJ.PayRcv), `wsRemoved` (CP.Exec ws-transfer), `gather` (CJ.CCWF). Diagnostic = a known current exception exists; check it as a canary, never as a guarantee.

- **ResourceUseMatchesAllocation**: `\A c \in Sites, j \in Jobs, g \in Gens: launch[c][j][g].state = "alive" => launch[c][j][g].env = Devices(alloc[c][j])   (explicit study env override excluded by config)`
- **SuccessorInputPreserved**: `\A c \in Sites: inSlot[c].gen \notin trainerReceived[c] => inSlot[c].params = "present"   + liveness \A c,k: delivered(c,k) ~> (submitted(c,k) \/ runAbort)`

- **SendSuccessRequiresAuthority**: `\A r \in Results: tpSend[r] = "success" => canonical[TaskOf(r)].resultId = r`
- **TaskAbortDoesNotStopSuccessorWorkflow**: `[]((busyReplaced /\ ~runAbort /\ ~workflowEndReq) => ~askedToStop)   + liveness \A r: acked(r) ~> (executed(r) \/ rejected(r))`
- **OneAssignmentRecordPerIdentity**: `\A t, x: Cardinality({i \in DOMAIN clientTasks[t] : clientTasks[t][i] = x}) <= 1 /\ (runActive => monitorAlive)   + liveness (standing(t) /\ allResponded(t)) ~> retired(t)`

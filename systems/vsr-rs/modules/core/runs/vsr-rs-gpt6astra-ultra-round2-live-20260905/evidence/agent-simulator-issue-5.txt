Closing: we went TigerBeetle VOPR-style instead of MadSim. The library was reshaped so a replica is a state machine its owner steps, with no I/O or threads of its own (f9a6d4e), and the simulator in simulator/ drives it deterministically from a seed that decides the whole configuration: cluster size, request rate, network loss, replay and delay, crashes, restarts, and reboots that wipe a replica's memory (8b1271c, 5f4c413, 949b3d7). It checks safety properties every tick and requires a random majority to converge once faults stop. Every bug fixed since then was found by it and is recorded in the commit message with its seed.

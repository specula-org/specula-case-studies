## Mechanisms carried as reference context

- **Timer creation bits are obligations, not proof timers ran.** `3491846fe` changes XOR to AND-NOT so retry clears per-attempt bits rather than spuriously setting absent bits. `11e54a1b9` reverts the optimization that deleted heartbeat timer tasks on heartbeat receipt: the old timer is needed to reconsider the latest heartbeat deadline and generate its successor. Both are fixed historical references, not MC hunts recreating the removed logic.
- **State mutation and retry task materialization share a transaction but have internal ordering.** `4c940aa7e` documents aliased ActivityInfo and the conflict between old size bookkeeping and generating tasks from outdated version/schedule. `183ee872c` moves generation after tracked mutation but still propagates generation errors. Model durable commit/abort outside tentative mutation; do not assume an error locally leaves the cached pointer unchanged without following cache cleanup.
- **Backend precision is part of timeout applicability.** Full `331573389` includes queue-side `IsTimeExpired`, truncating both comparison times to millisecond resolution, and updates heartbeat-mask deduplication as well as Activity expiration. `1b482d5b4` preserves subsecond retry intervals by using nanosecond duration math and explicit nil expiry. Bounds must state time representation; historical rounding defects are reference only.
- **RPC handoff and protected aliases differ.** `5c53b4d5` copies memo/search attributes/child state before lease release and annotates Activity transfer/retry paths. Its actual behavioral fixes were mainly sibling transfer/visibility paths; do not count those as reproduced ordinary Activity corruption. It motivates checking what request data is copied before releasing the lock.
- **A durable write is not necessarily a new replicated application transition.** `30e3e55dc` keeps timer task-status writes in persistence updates while removing them from user-data transition markers. Full diff includes task refresher and standby timer paths. `d7d6d9edb` centralizes close-transaction ordering: WFT conversion before event preparation, timer task generation at the end, state transition history separate from DB update count. Trace sequence numbers must not assume any one of those is a universal persisted commit ID.
- **Observation fields can be derived, rather than direct evidence.** `026200f95` reports retry interval only when `now < ScheduledTime && !Paused`. The else comment says dispatched to Matching, but the predicate does not observe Matching acceptance. PendingActivityInfo must not be used as independent proof that handoff completed. `7979ad0ef` repairs size accounting on start/heartbeat alias writes; it does not alter their attempt acceptance contract.
- **Deliberate limitations must remain assumptions.** `6e48e9969` intentionally drops scheduled tasks more than 99 years away. `1be76e358` makes nil protobuf timestamps convert to Unix epoch unless callers use nil-safe utilities, and prohibits shallow value copies of proto lock fields. `c9d9a9342` moves workflow cache to host scope: cache eviction and shard reacquisition are different recovery experiments.

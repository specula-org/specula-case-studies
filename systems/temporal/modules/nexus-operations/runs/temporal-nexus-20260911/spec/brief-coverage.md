## Scope, backend and assumptions

- One cluster, namespace, Workflow Run and stable registered external endpoint; legacy HSM routing. The pinned source and brief use CHASM workflow-operation flag=false, rollout=0, transition history=true, outbound reader enabled, cancel-ACK events=true. Request timeout/minimum are abstracted from the brief's 10s/1.5s to ordered model time units. Configuration normalization is an input precondition: positive S2S/STC do not exceed positive S2C.
- SQL/SQLite atomic mutable-state transaction: HSM node state, logical timers, buffered events and new queue tasks commit together. Raw history append precedes this transaction. `UnknownCommitted` and `UnknownNotCommitted` have the same error-facing behavior. Notification is not a commit oracle. `DBRecordVersion` and RangeID are distinct.
- Brief backend evidence is SQLite `mode=memory, cache=shared` plus readback/shard reload; it is not process/power-loss persistence evidence. No backend is launched in spec generation.
- Protocol-conforming headers, immutable request identity, stable async token and endpoint request-ID dedup/retention are assumed. These assumptions do not promise exactly-once arbitrary endpoint effects. An expired request can still reach the endpoint; its response can arrive after the caller stopped waiting.
- HSM initial transition identity is distinct from the task's generation watermark and serialized attempt. Task `Attempt` is observed but is never an equality fence. Callback identity is operation-level, not attempt-level. The single-branch/single-run scope excludes failover-version branch divergence and legacy transition-history fallback.
- Durations are fixed normalized inputs, time advances monotonically, and request budgets are computed after the locked read. Each timer batch consumes the current persisted logical groups under one workflow lock, retaining a volatile workspace through all inner steps and committing once. Equal-deadline logical entries may be processed in either order. Timer-group Scheduled flags control creation of the earliest physical wake; physical wake copies are scheduler cues; they do not regenerate missing logical tasks.
- `node=FALSE` plus remaining operation fields is a trace observation ledger of the last transition, not a claim that deleted HSM data persists. Capacity uses actual node existence. Ordinary reload copies durable timers; explicit full refresh changes the generation and regenerates/filter tasks. Full history rebuild is not equated with either action.
- WFT internals are projected to an in-flight flag, buffer, and command/flush boundaries. Schedule/cancel commands include their WFT completion under the workflow lock. A separately modeled in-flight WFT makes asynchronous history buffered. Only closure with no unhandled buffered events is modeled. Buffered terminal versus closure rejection/flush policies beyond that precondition require a separate implementation-backed extension.

`EligibleProgress` is defined as a temporal leads-to obligation for enabled operation deadlines. It is not asserted under finite `TimeLimit`: a late start could otherwise run beyond the artificial horizon. RetryDelay is an explicit abstraction of a sampled positive retry delay, not a claim that the pinned exponential/jitter policy is constant; broader retry-timing traces require a source-backed delay refinement. A sound liveness run needs time divergence, fair eligible timer/outbound/commit steps, finite failures/churn, eventual shard/readback availability and an open workflow or permitted terminal closure. Endpoint progress needs its separate retention/delivery/health contract. No property demands that cancel ACK produce remote CANCELED. Absence of a publication is checked directly by `RequiredTimerPublished`, so the known B1 is reachable without an unjustified fairness assumption.

`PublishedTasksHaveCommit`, `HistoryAppendBacked`, `TerminalNodeConsistency` and `MCTypeOK` are structural checks, not extra discovery counts. `PublishedTasksHaveCommit` is a bookkeeping sanity check; real publication independence must be established by the trace's backend observations. Counter records are included in the temporal state vector. `ProtocolView` is an inspection-only projection; it is not used to merge states with different remaining fault budgets. Symmetry acts on operation model values, never on time, attempt numbers or distinct queue copies.

## Repairs

1. **Direct-action domains.** Every parameterized base action now checks the same domains as `Next` before indexing state. `TypeOK` checks requested IDs and call identity/stage. Legal `Next` behaviors are unchanged. [parameter-domain-audit.json](output/validation-round-1/parameter-domain-audit.json) enumerates the guards. This resolves review R3.
2. **Normal start response ordering.** `recordworkflowtaskstarted/api.go:232-258` constructs the response and calls Registry.Send inside the mutation callback; `update_workflow_util.go:70-113` persists only afterward. Construction now makes a `pendingStart` response for a normal task. Successful persistence makes it returnable; the new `RecordWorkflowTaskStartedReturn` exposes it outside the lease after History assembly. Speculative starts retain legitimate skipping. Cache clearing drops uncommitted responses; process loss drops server-local pending responses. Fresh normal traces capture the new actual return probe. Separate History-assembly error/lost-start-response schedules remain unmodeled and untested.
3. **Acceptance cache insertion.** `mutable_state_impl.go:5794-5831` writes UpdateAccepted to the event cache before commit. `OnAcceptanceMsg` now includes that entry, preserving whole-state comparison.
4. **Record-version timing.** `mutable_state_impl.go:7895-7898` increments the in-memory version at transaction close. `ctx.rv` now advances when preparing the write; `write.rv` retains the expected previous database version, matching `sql/execution_util.go:653-654`. Database version still changes only at commit.
5. **Append timeout ordering.** SQL `execution.go:338-357` and Cassandra `execution_store.go:114-125` return append errors before execution submission. `AppendHistoryTimeout` no longer settles an executing transaction. Execution uncertainty and shard reacquisition remain distinct. This resolves the reviewed R4 guard omission; the constrained fixtures are not unrestricted convergence.

Full post-state equality, all enabled safety properties, the supplied hunt bounds, and zero silent actions are preserved. Generators and action mappings were synchronized; relevant completion-event source ranges were extended through the actual event mutation.

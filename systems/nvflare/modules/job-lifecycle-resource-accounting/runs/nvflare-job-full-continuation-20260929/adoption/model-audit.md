## Invariants and search exclusions

All 27 actual cfg files were parsed in adoption/static-checks.json. None was inferred from old coverage prose.

- TerminalStable is a strong contract hypothesis grounded in CLI terminality and abort's refusal of finished jobs. It also rejects terminal-to-terminal corrections; classify each such counterexample against intended precedence, not merely the FINISHED prefix.
- AbortHonored starts at a successful “before running it” acknowledgment; a job that was already launched cannot retroactively be unlaunched. postAckLaunch checks subsequent launches. OneShot counts SJ launches only, not arbitrary child/spawn counts.
- RunningIsTracked permits a runner-owned window. It says nothing about a live process that was never inserted. SlotBalance checks an abstract set and Boolean start/end history; it is not an exactly-once event-count invariant.
- ResourceConservation uses discrete list units. ExclusiveOwnership uses job identity, so two allocations to the same job are not two distinct holders (conservation may still detect multiplicity). NoFreeWhileGroupAlive assumes descendants use those units. These do not establish GPU memory arithmetic or environment binding.
- FinalMatchesOutcome uses ever-recorded history, not solely signals available before an irreversible latch. Distinguish (i) pending accepted, (ii) authoritative failure recorded, (iii) late report after finality. Do not weaken the source contract merely to remove MC-U1; do not demand retroactive finality without a source guarantee.
- TypeOK checks a subset of the 55 variables. ReservationBounded only checks ttl in 1..Expiry; no real-time bound follows. RunningWasStarted and PublishHasLatch are useful structural checks, not independent conformance evidence.
- PromptCancel and StartFailureMatchesPolicy are probes, not established guarantees. F6's expiry fallback and default non-strict timeout policy are deliberate modeled behaviors. SjErrorNotMasked tests ground truth under best-effort delivery and requires a failure-contract decision.
- AdmissionProgress is conditioned only on non-poisoned jobs but depends on fair scheduling, resource availability and configured failure bounds. BoundedFinalization is eventual removal, not a 900-second theorem. EventualCleanup presumes normal child/descendant termination through fairness and exempts dead CPs.

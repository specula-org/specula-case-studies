Hi @chanfm81 thanks for the question.

For NVFlare 2.2.x, the job is submitted to the NVFlare server.
If you use admin command "list_jobs" you should be able to see the job id of that submitted job.

If the job is ready to deploy and run, the NVFlare server will then deploy the corresponding apps into each sites.
Those apps will be put inside [site-1]/[job id], so no longer inside the [site-1]/[transfer] folder anymore.

Please refer to the documentation for concepts of jobs and apps: https://nvflare.readthedocs.io/en/latest/real_world_fl/job.html

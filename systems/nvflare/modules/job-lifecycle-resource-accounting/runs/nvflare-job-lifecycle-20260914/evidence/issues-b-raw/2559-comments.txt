Hi @dirkpetersen thanks for the issue!

Our default implementation of GPUResourceManager is this: https://github.com/NVIDIA/NVFlare/blob/main/nvflare/app_common/resource_managers/gpu_resource_manager.py#L43

So in your case you can specify 15 instead of 16.


This implementation is opinionated that only takes in memory in GB and it will multiply it by 1024 https://github.com/NVIDIA/NVFlare/blob/main/nvflare/app_common/resource_managers/gpu_resource_manager.py#L72

But you can refer to the code and write your own ResourceManager that is design for your specific needs.

After the dashboard generates the provision kits, you can go inside and edit each client site's "resource.json" file, for example:

```
{
  "format_version": 2,
  "client": {
    "retry_timeout": 30,
    "compression": "Gzip"
  },
  "components": [
    {
      "id": "resource_manager",
      "path": "path_to_your_code.MyGPUResourceManager",
      "args": {
        "num_of_gpus": 0,
        "mem_per_gpu_in_GiB": 0
      }
    },
    {
      "id": "resource_consumer",
      "path": "nvflare.app_common.resource_consumers.gpu_resource_consumer.GPUResourceConsumer",
      "args": {}
    }
  ]
}
```

## Pull request overview

This PR fixes two related filter-chain behaviors in NVFlare’s messaging pipeline: (1) job-configured task filters now honor executor-style `*` task patterns with exact task names taking precedence, and (2) `DXOFilter` now invokes `process_dxo` even for empty leaf DXOs so initialization-style filters can populate data. It also updates several data-dependent filters to safely skip empty input, documents the behavior, and adds regression tests.

**Changes:**
- Add wildcard (`*`) task-pattern matching to `apply_filters` configuration lookup, preferring exact task matches.
- Adjust `DXOFilter` to call `process_dxo` for matching leaf DXOs even when their data is empty.
- Add/extend tests and documentation covering wildcard task filters and empty-DXO behavior, and update several filters to skip empty DXO data safely.

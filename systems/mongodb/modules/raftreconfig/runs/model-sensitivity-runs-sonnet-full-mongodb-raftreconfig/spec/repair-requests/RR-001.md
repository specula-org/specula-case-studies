## Trigger

The counterexample requires `BecomeLeader(n1)` when `n1 ∉ config[n1]` — a state
that is structurally impossible in the real code because `_heartbeatReconfigFinish`
sets `selfIndex = -1` when the node is not in the new config, and
`processReplSetRequestVotes` rejects the vote request when `_selfIndex == -1`.

## Evidence

- **CE step that cannot be reproduced**: `MCBecomeLeader(n1)` in the counterexample
  occurs when `n1.config = {n3}` (n1 is not a member of its own config). In the
  real code, after `_heartbeatReconfigFinish` installs a config that excludes n1,
  `selfIndex` is set to `-1`. With `selfIndex = -1`:
  - `processReplSetRequestVotes` returns `ErrorCodes::InvalidReplicaSetConfig`
    (`replication_coordinator_impl.cpp` — guard: `if (_selfIndex == -1) return ...`)
  - `becomeCandidateIfElectable` fails (node is not a voting member)
  - Election cannot be started.

- **Additional safeguard**: `_shouldStepDownOnReconfig` 
  (`replication_coordinator_impl_heartbeat.cpp`) returns `true` when the node is
  primary and the new config does not include it. The primary STEPS DOWN **before**
  `_setCurrentRSConfig` installs the new config. So a primary can never be in a
  stable state with `config[self] ∋ self == false`.

- **Spec model gap** (missing guard): The TLA+ `BecomeLeader(n)` action lacks the
  precondition `n ∈ config[n]`. The real code enforces this via `selfIndex ≥ 0`.

- **Code citations**:
  - `replication_coordinator_impl.cpp`: `_selfIndex == -1` guard in
    `processReplSetRequestVotes` (≈ line 5350)
  - `replication_coordinator_impl_heartbeat.cpp`: `_shouldStepDownOnReconfig` —
    returns `_memberState.primary() && !(myIndex.isOK() && ...isElectable())`
  - `replication_coordinator_impl_heartbeat.cpp:1067`: `myIndex = StatusWith<int>(-1)`
    when `NodeNotFound` (node not in new config)

## Proposed change

Add a precondition to `BecomeLeader(n)` in `base.tla`:
```tla
BecomeLeader(n) ==
    /\ n \in config[n]      (* NEW: node must be in its own config *)
    /\ ...
```

This models the real-code invariant that only members of a config can run for
election. The `selfIndex = -1` mechanism in the implementation is the enforcement
point.

================================================================================
TRACE EVENT SCHEMA
================================================================================

All events emit valid NDJSON with:
  - "tag": "trace" (mandatory for Trace.tla)
  - "event": action name (e.g., "encode_message")
  - "role": "requester" or "responder"
  - "session_id": session identifier (e.g., "sid_0")
  - "timestamp": real nanosecond timestamp (monotonic)
  - "state": current session state snapshot
  - "message": action-specific fields

Example event:
{
  "tag":"trace",
  "event":"encode_message",
  "role":"requester",
  "session_id":"sid_0",
  "timestamp":1000000000,
  "state":{"session_state":2,"request_seq_num":0},
  "message":{"sequence_number_before":0,"sequence_number_after":1,"key_used":"key_0"}
}
